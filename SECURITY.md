# Security

## Report a vulnerability

Do not open a public issue for a security problem. Use GitHub's private reporting
(Security tab, "Report a vulnerability") or write to hello@contact.cliffiscurious.com.
Say what you found, how to reproduce it, and what it lets someone do. You get an answer within a week.

## What counts

Anything that lets a web page, a file, a link or a message make Adam Studio read, write, download
or run something the creator did not ask for, and anything that could alter what an update installs.

## Updates and releases

- Installers and updates are built and published only by the maintainer, from the maintainer's machine, to
  `Michel-cliff/adam-studio-releases`. A contribution to this repository never ships by itself: it is read,
  merged by the maintainer, and only then may end up in a later release.
- Installers are not code-signed yet. If you see a release that is not listed on `adam-studio-releases`
  under the maintainer's account, do not install it.
